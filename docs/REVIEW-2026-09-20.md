# Sync incident review, 2026-09-20

## Incident and causes

The scheduled Weekly Pages Sync on 2026-09-14 failed in Endfield 1.0 with `unable to determine durationDays from sheet`:
https://github.com/Sunriseex/gacha-pull-bookkeeper/actions/runs/34832065061

Publication was skipped, preserving the deployed site. The prior tests passed because their CSV fixtures did not reproduce GViz's automatic header/type inference. A live request without an explicit header count dropped duration and column labels; `headers=1` returned the correct 49-day duration and release date. Version-tab requests now specify that header count. Data/Summary retain their existing layouts.

Checking all other sources revealed a second blocker: WuWa's new `3.7 (WIP)` tab has no Data summary column yet. Only new, explicitly marked WIP/STC WuWa versions without summary data are deferred, with a named log entry. Missing summary data for an existing version or an unmarked release remains fatal. An all-deferred sync cannot report success.

Review also found that sparse summary headers could imply contradictory offsets. Choosing a Go map entry as the anchor could then assign another version's values. Every explicit header must now agree with the inferred mapping; conflicts abort without writing.

## Prevention

- Regression test reproduces missing metadata unless the correct request parameter is sent.
- Tests cover a new draft, an existing draft, and a released version missing summary data; existing files remain unchanged on failure.
- Conflicting header anchors are tested repeatedly to cover map iteration order.
- A single compiled parser checks every game, collecting all errors instead of exiting at the first game.
- Publication remains blocked if any game fails; the deployed site remains unchanged.
- Per-game ten-minute timeout, bounded subprocess output, workflow timeouts, an Actions summary, and per-game log artifacts retained for 14 days.
- A CLI integration test proves that partial failure returns exit code 1 while saving all five logs and a blocked-publication summary.
